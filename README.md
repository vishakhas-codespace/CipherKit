# CipherKit 🔐
A C++ command line encryption toolkit implementing 
3 classic cryptography algorithms.

## Features
- Caesar Cipher (encrypt & decrypt)
- Rail Fence Cipher  
- Columnar Cipher

## How to run
Compile: g++ cipherkit.cpp -o cipherkit
Run: ./cipherkit

## Built with
C++

## Why I built this
Part of my AI x Cybersecurity learning journey.
These are the foundational algorithms that modern
cryptography evolved from.
